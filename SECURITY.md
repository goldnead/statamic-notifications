# Security policy

## Supported versions

The latest minor of the current major receives security fixes. Older minors do
not.

## Reporting a vulnerability

Report privately to **info@adriangoldner.com**, or through GitHub's private
vulnerability reporting on this repository. Do not open a public issue.

Please include the addon version, the Statamic and Laravel versions, and the
smallest reproduction you have. You will get an acknowledgement; a fix follows
as fast as the severity warrants.

If the problem is in Statamic itself rather than in this addon, report it to
<https://statamic.com/security> instead — they have a coordinated process and
this repository does not.
